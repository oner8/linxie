# 标注工具

本地工具，用来维护 `data/videos.json`：为每一集标定田字格的裁切框，并给每个字记录起笔时刻。两者在同一个页面完成。

工具只在 `127.0.0.1` 上运行，不会部署，也不会打进镜像。

## 运行

```sh
node tools/annotate/server.mjs          # 默认 http://127.0.0.1:8080
PORT=9000 node tools/annotate/server.mjs
```

首次运行需要 `BILIBILI_SESSDATA`（写入 `.env` 即可，脚本不会自动读取，需从环境变量传入），用来拉取分P元数据并缓存到 `data/annotations/pages.json`。之后有缓存就不再需要。

```sh
set -a; . ./.env; set +a
node tools/annotate/server.mjs
```

## 标定裁切框

1. 拖动进度条到画面清晰的一帧
2. 依次点田字格的**四个角**（左上 → 右上 → 右下 → 左下）
3. 右侧预览实时显示裁切后的效果
4. 第 4 个角落下即保存

裁切框按**集**存储：`parts[集号].cx / cy / half`，其中 `half` 是正方形半边长占画面高度的百分比。

## 记录时间点

1. 播放视频（可点 `1×` 切到 0.5× 或 0.75×）
2. 某个字起笔时，点右侧对应的字块
3. `end` 自动取下一个字的起点；最后一个字取「起点 + 20 秒」或该集时长
4. 空格键 = 给下一个未标注的字打点

时间点写进 `parts[集号].chars[字] = [start, end]`。

「整集播放」按钮把整集所有字一次写成 `[0, 时长, 1]`，用于没有评论标注、又不想逐字标的集。

## 快捷键

| 键 | 作用 |
|---|---|
| `空格` | 给下一个未标注的字打点 |
| `←` / `→` | 后退 / 前进 2 秒 |

## 注意

- 每次操作直接写回 `data/videos.json`，没有撤销以外的缓冲，改动前建议先提交一次
- 字表的书写顺序取自分P标题；标题缺失时退回文件里的键顺序
- 存盘时字符按键码排序，便于 diff
